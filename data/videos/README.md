# 📹 Purplle CCTV Videos Ingestion Directory

Place raw storefront CCTV footage inside this directory.

## Expected Specifications:
- **Format**: `.mp4` or `.avi` container formats.
- **Resolution**: 1080p (1920x1080) or 720p (1280x720) preferred.
- **FPS**: 25 FPS or 30 FPS constant framerate.
- **Codecs**: H.264 / AVC video codecs.
- **Filename**: Should align with calibrated cameras index, e.g., `CAM-MAIN-01.mp4`.
