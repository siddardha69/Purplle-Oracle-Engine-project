# 🛠️ Purplle Data Repositories

This workspace contains system-generated analytical files:
- **`processed/`**: Stashes normalized/resampled frames sequences or chunked videography fragments.
- **`outputs/`**: Exports visual recordings and tracking trace overlays.
- **`validation/`**: Contains validation reports and telemetry scans.
- **`metadata/`**: Tracks active dataset ingestion registries.
